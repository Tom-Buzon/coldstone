# Projets Blender du Workbench

Les fichiers `.blend` sauvegardés depuis le panneau **Spartan Anim** sont
rangés ici par portée, cible et action. Ce sont les sources éditables : les GLB
exportés sous `assets/animations/source_packs/custom` ne les remplacent pas.

Le fichier `.gdignore` empêche Godot d'importer ces sources de travail.
