# PROJECT HOPLITE — SFX sources

The patch includes small original procedural fallback WAV files so the project works offline immediately.

`SETUP_AUDIO.bat` optionally replaces those fallback files with the selected CC0 source recordings below.

## CC0 source pack

**Various Sound Effects** — Spring Spring / Julie Damsgaard — OpenGameArt

- License: CC0
- Source page: https://opengameart.org/content/various-sound-effects-0
- Selected source files: `snd_enemysword.wav`, `spear.wav`, `snd_throw1.wav`, `player_hit.wav`, `snd_splathit.wav`, `snd_bullethit.wav`, `snd_splat.wav`, `snd_splurt.wav`, `crush.wav`, `snd_menu_move.wav`, `snd_menu_select.wav`, `uff.wav`, `snd_death1.wav`.

The filenames are normalized on download to the stable names expected by the game scripts in `res://audio/sfx/`.
