# Animation data generated for the game

Ce dossier contient uniquement les sorties générées par le Spartan Animation
Workbench. Ne pas modifier `runtime_bindings.json` à la main : utiliser le
Workbench puis `ANIMATIONS_3_PUBLIER_JEU.bat`.

Le runtime garde ses correspondances historiques si ce fichier est absent ou
si une entrée ne passe pas la validation.
