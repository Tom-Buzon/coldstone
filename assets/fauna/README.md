# Faune Quaternius

Assets inclus sous licence **CC0 1.0** :

- `quaternius_ultimate_animated_animals/models/` : les 12 modèles glTF du [Ultimate Animated Animal Pack](https://quaternius.com/packs/ultimateanimatedanimals.html), avec leurs animations embarquées.
- `quaternius_eagle/Eagle.glb` : uniquement l'aigle du [Animal Pack Vol.2](https://opengameart.org/node/78596), converti depuis le fichier source Quaternius pour un import Godot fiable. Les clips `Idle` et `Flying` sont conservés.

Auteur : Quaternius. Les deux sources autorisent l'utilisation personnelle et commerciale via la dédicace au domaine public CC0.

La source Blender de l'aigle est conservée dans `_source/fauna/quaternius_eagle/Eagle.blend`. Le script reproductible `tools/import_quaternius_eagle.py` produit le GLB utilisé par le jeu.

## Faune Sketchfab

- `sketchfab_pterodactyl/pterodactyl.glb` : **Animated Flying Pteradactal Dinosaur Loop**, par LasquetiSpice, sous licence [CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). Source : https://skfb.ly/o9nTY

Le ptérodactyle est utilisé comme faune aérienne décorative : animation de vol active, ombres et collisions désactivées par le système de faune.
